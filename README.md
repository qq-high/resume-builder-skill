# 简历构建助手 (Resume Builder)

> 基于招聘要求和求职者基本信息，一键生成高质量中文求职简历

## ✨ 核心功能

- 🎯 **JD 精准匹配**：智能分析招聘要求，将关键词融入简历
- 📊 **STAR 法则优化**：每段经历都结构化、有说服力
- 📈 **量化成果呈现**：用数据说话，展示真实价值
- 💼 **智能项目推荐**：根据岗位推荐项目创意和学习资料
- 📚 **学习路径指导**：附上完整的学习资源清单
- ✅ **可直接使用**：输出 Markdown 格式，可直接转换为 PDF/Word

## 📋 使用流程

1. **提供信息**：JD + 个人信息（或已有简历）
2. **智能分析**：提取关键词、匹配经验
3. **生成简历**：输出 Markdown 格式简历
4. **附加价值**：推荐项目创意 + 学习资料 + 面试准备

## 💡 简历生成原则

### 必须遵守
- ✅ 诚实原则：所有信息必须真实
- ✅ 量化优先：用数据说话
- ✅ STAR 法则：每段经历结构化
- ✅ 关键词匹配：JD 关键词自然融入
- ✅ 强动词开头：避免"参与""协助"

### 推荐做法
- 🎯 一份简历对应一个职位方向
- 🎯 控制在 1-2 页 A4 纸
- 🎯 每段工作 3-5 条核心 bullet
- 🎯 项目经历 2-3 个最佳
- 🎯 持续迭代，根据面试反馈优化

## 📝 输出示例

生成的标准简历包含：
1. **个人信息**：姓名、联系方式、求职意向
2. **个人简介**：3-5 句话核心优势
3. **核心技能**：按 JD 优先级排序
4. **工作经历**：倒序 + STAR 法则 + 量化成果
5. **项目经历**：技术栈 + 个人贡献 + 量化成果
6. **教育背景**：学校、专业、成绩
7. **证书认证**：相关证书
8. **推荐项目**：智能推荐（参考 `project-ideas.md`）
9. **学习资源**：附完整学习路径（参考 `learning-resources.md`）
10. **面试准备**：高频问题预测
